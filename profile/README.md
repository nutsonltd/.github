# Nutson

[nutson.us](https://nutson.us)

## Формы задач

- `Bug`: сообщение о неисправности
- `Dependencies`: обновление зависимостей
- `Design`: постановка задачи по дизайну
- `Docs`: изменение документации
- `Epic`: крупная инициатива с дочерними задачами
- `Feature`: добавление новой возможности
- `Management`: управленческая задача
- `OPS`: операционная задача
- `Package`: создание пакета
- `Product`: продуктовая задача
- `Repo`: создание репозитория
- `Security`: задача безопасности без публикации секретов
- `Service`: описание назначения и контрактов сервиса

## Шаблоны PR

- `bugfix.md`: исправление дефекта с проверкой до и после
- `feature.md`: добавление возможности с основным и дополнительным сценариями
- `service.md`: изменение сервиса и его контрактов
